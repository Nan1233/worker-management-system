# Cập nhật tên công ty

Đã đồng bộ tên hiển thị thành **KTC (HANOI) CO., LTD** tại:

- Trang đăng nhập bản desktop và mobile.
- Sidebar quản lý / tổ trưởng / quản trị.
- Header khu vực quản lý.
- Header giao diện công nhân.
- Tiêu đề trình duyệt.
- Tên và mô tả PWA.
- Trang thông báo mất kết nối.

Build lại frontend:

```bat
npm install
npm run build
```

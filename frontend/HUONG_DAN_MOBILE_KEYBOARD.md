# Sửa bàn phím di động iOS và Android

- Phát hiện bàn phím bằng `window.visualViewport` kết hợp chiều cao màn hình cơ sở.
- Hỗ trợ Safari iOS, Chrome Android, Samsung Internet và PWA.
- Khi bàn phím mở: ẩn thanh điều hướng dưới và thanh Lưu/Làm mới.
- Hiện nút `Ẩn bàn phím` và tự cuộn ô đang nhập vào vùng nhìn thấy.
- Khi bàn phím đóng: tự khôi phục thanh điều hướng và thanh thao tác.
- Không thay đổi backend hoặc cơ sở dữ liệu.

Build:

```cmd
npm --prefix frontend run build
```

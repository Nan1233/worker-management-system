# Poketto UI Source of Truth

The UI primitives under `src/components/poketto/ui` are copied from `poketto-stack-main/packages/ui/src/components/ui` and adapted only for local module paths.

KTC business logic, APIs, validation, permissions, and workflow code are retained. Legacy KTC CSS imports are disabled from the application entry/pages so the Poketto/Tailwind design system is the visual source of truth.

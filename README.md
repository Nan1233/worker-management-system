# KTC Production Control

## Kiểm tra toàn dự án

Chạy `verify-project.bat` hoặc `npm run verify`.

## Build ứng dụng Windows

Chạy `build-exe.bat`. File tạo ra có tên thường, không kèm số phiên bản:

- `KTC-Production-Control-Setup.exe`
- `KTC-Production-Control-Portable.exe`

## Commit và triển khai

Sau khi cài Git for Windows, chạy `commit-code.bat`. Script chỉ commit khi toàn bộ kiểm tra thành công.

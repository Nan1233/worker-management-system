# Poketto Stack integration — KTC Worker

This release starts the real template migration using the uploaded Poketto Stack source as the Worker workspace layout reference.

- Source template: TinsFox/poketto-stack
- Adapted pattern: sidebar + workspace shell + responsive mobile navigation
- KTC API, routing, auth, permissions and production business logic are preserved.
- Approve/Reject code is untouched.
- This is intentionally the first migration slice: Worker shell first, then Worker pages, then Lead, Manager and Admin.

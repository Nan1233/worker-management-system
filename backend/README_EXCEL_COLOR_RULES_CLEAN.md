# Quy tắc màu Excel sạch

- Xóa toàn bộ conditional formatting cũ trong template để tránh màu đỏ/vàng tự ghi đè.
- Số SP/H: nền xanh lam nhạt cố định.
- OK: nền xanh lá nhạt cố định.
- Các cột lỗi chi tiết (ví dụ Vỡ cao su): nền trắng, không tô theo giá trị.
- Chỉ Tỷ lệ đạt và Tỷ lệ NG được chia màu theo mức độ.

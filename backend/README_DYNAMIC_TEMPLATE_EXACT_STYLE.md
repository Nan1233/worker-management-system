# Excel động giữ nguyên style file mẫu

- Không tạo workbook hoặc giao diện mới.
- Luôn mở `templates/bao-cao-cat-long-export.xlsx`.
- Giữ nguyên phần biểu mẫu phía trên hàng 326, logo, merged cells, màu, font, viền và page setup.
- Chỉ dựng động bảng dữ liệu từ hàng 326 theo danh mục trừ giờ/lỗi NG active của công đoạn.
- Style từng cột lấy đúng từ cột tương ứng trong mẫu: K cho chi tiết trừ giờ, AJ cho chi tiết NG.
- Mapping đúng của mẫu: AD Số SP/H, AE Ngày/Tháng, AF Tỷ lệ đạt.
